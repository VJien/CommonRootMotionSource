# 到达模式

每个运动都有两种到达模式，区别只在**被阻挡之后怎么办**。

| 模式 | 行为 | 结果 |
| --- | --- | --- |
| `Guaranteed`（默认） | 每帧把角色补到“此刻应在的位置”，被挡的位移会在之后找补回来 | 时长结束时一定在终点 |
| `Incremental` | 每帧只走这一帧应走的位移，与角色实际位置无关 | 被挡的位移永久丢弃，可能到不了终点 |

## 举例

目标 1000 厘米、时长 1 秒、每帧 0.1 秒。第 3 到 5 帧被墙挡住。

- `Guaranteed`：结束位置 = 1000（找补回来）。
- `Incremental`：结束位置 = 700（丢掉了 3 帧 × 100 厘米）。

## 怎么选

- **冲刺、位移技能、技能位移**：通常用 `Guaranteed`，玩家期望“这个技能一定把我送到那儿”。
- **普通移动式的推进、被挡住就该停下的场景**：用 `Incremental`，手感更接近正常移动，贴着墙不会一直被往墙里拽。

## 联网注意

`Incremental` 下，服务器和客户端被挡的帧数可能不同，位置会**永久分叉**，只能靠角色移动组件自带的服务器位置校正拉回来。
如果发现两端持续拉扯，优先检查这一点。

`Guaranteed` 有自校正性质：两端即便中途有偏差，也会收敛到同一个目标点。

## 与引擎的 `AccumulateMode` 的区别

这两个概念容易混：

- `ReachMode`（本插件）：被挡后是否找补。
- `AccumulateMode`（引擎）：本运动的速度与角色**已有速度**是覆盖还是叠加。

两者互相独立，可以任意组合。

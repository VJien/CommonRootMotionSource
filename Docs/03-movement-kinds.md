# 移动方式

通过 `Params.PathKind` 选择路径形状。

> 下面所有坐标（起点、终点、路径点）的语义都是**角色胶囊中心**，不是脚底。射线打地面的命中点要先经 `Foot To Center` 转换，见 [01](01-request-and-params.md)。

| 种类 | 需要的字段 | 说明 |
| --- | --- | --- |
| `Straight` | `StartLocation`、`TargetLocation` | 点到点直线 |
| `Polyline` | 起点 + `PathPoints` | 依次经过各点的折线 |
| `Spline` | 起点 + `PathPoints` | 经过全部点的 Catmull-Rom 平滑曲线 |
| `Parabola` | 起点、终点、`ArcHeight` | 解析抛物线，`ArcHeight` 是顶点高度 |

折线与样条的终点取**最后一个路径点**，`TargetLocation` 被忽略。路径点最多 64 个，超出会被截断并写 Warning。

## 匀速参数化

折线与样条按**弧长**参数化，不是按点序号。所以点距悬殊时速度仍然均匀：
第一个点和第二个点相距 10、第二个和第三个相距 1000，走起来不会在短段突然飞快、长段突然变慢。

如果希望速度变化，用 `Ease` 或 `CustomProgressCurve` 调整时间到位移的映射。

## 抛物线

- `ArcHeight` 是顶点距起终点连线的**高度**，起终点处为 0。
- 起终点不等高时，终点高度仍然精确。
- 抛物线自带高度，`Params.ArcHeight`（正弦弧线）在抛物线路径下**不会**再叠加。

直线与多点路径使用 `Params.ArcHeight` 的正弦弧线：起终点为 0，中间隆起。两者选一个即可。

## 曲线偏移（`OffsetCurve`）

在任意路径形状上再叠加一条偏移曲线（`UCurveVector`）：

- 横轴是**位移进度** 0～1（已过缓动），不是时间。
- 纵轴是偏移向量，单位厘米。
- 在**朝向空间**中给定：
  - **X** = 沿起点到终点的水平前进方向
  - **Y** = 其右侧
  - **Z** = 世界上方
- 只转换一次。不要自己再按朝向旋转一遍，否则路径会扭曲。

曲线为空表示无偏移。数组在两端需要能解析到同一资产，详见 [07](07-networking.md)。

**注意：** 插件不会把曲线端点归零。如果曲线在进度 0 或 1 处不为 0，角色会从偏移后的位置开始/结束。需要精确落在目标上时，请让曲线在两端为 0。

## 自定义位移曲线（`CustomProgressCurve`）

替代 `Ease` 的位移映射：横轴时间进度 0～1，纵轴位移进度 0～1。留空即使用 `Ease`。
同样需要两端能解析到同一资产。
